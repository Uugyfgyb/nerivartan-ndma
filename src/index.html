一滴墨的来历Nerivartan 里那个 0.52 ppm 的信号：从哪里来，怎么认，怎么防

一缸清水里滴进一滴墨，肉眼看不出来，墨却还在。CSU O.W.C.A. 制药的降压药原料 Nerivartan，在痕量亚硝胺筛查里出现了一个约 0.52 ppm 的未知信号，而常规的 UHPLC-UV 对它毫无知觉。这一卷沿着你的摘要走：先看两份批记录差在哪里，再顺着工艺把每一步化学摊开，最后落到怎么确证、怎么防。

变了的两件事，各自对上一种原料

换成回收 DMF，带来了胺（DMA 升到 12 倍以上）。少洗一次，留下了亚硝酸根（升到 8 倍）。生成亚硝胺需要的正是这两样，再加上酸。案例

没变的 pH 才是底色

2.8 和 2.9 都落在仲胺亚硝化最快的那段 pH 里（见「速率」一章）。pH 不是这次的变量，它是一扇一直开着的门。推断

两个「没看见」，都不等于「没有」

UHPLC-UV 的定量限约 500 ppm，比限度高 1250 倍，看不见亚 ppm 的东西很正常。旧工艺则从来没做过痕量筛查。所以「旧工艺没问题」这句话，目前没有数据支持。待检验

含量 99.70%，为什么照样放行

标准只要求含量 ≥ 99.5%，等于给「其他成分」留了 5000 ppm 的余地。11.8 mg/L 的 DMA 折合约 12.5 ppm（按 DMF 密度 0.944 g/mL），只占这块余地的四百分之一。含量这项指标对它是盲的。补充

限度是怎么来的

NDMA：96 ng/天0.240 g/天 = 400 ng/g = 0.40 ppm
NDEA：26.5 ng/天0.240 g/天 ≈ 110 ng/g = 0.11 ppm

可接受摄入量（AI）除以最大日剂量 240 mg。案例

0.52 ppm 意味着什么

如果它确实是 NDMA：0.52 µg/g × 0.240 g = 125 ng/天，是可接受摄入量的 1.3 倍。如果它其实是 NDEA，那就是限度的 4.7 倍。同一个数字，身份不同，严重程度差出几倍，所以要先认身份，再谈超没超。

反应全谱：三条河，两处汇流

Every reaction in the pot

釜里的化学可以看成三条河。一条是做药的主线，腈和叠氮长成四唑；一条是淬灭剂，亚硝酸钠在酸里变成亚硝化物种；一条是溶剂，DMF 裂出二甲胺。亚硝化物种本来只该和残余的叠氮相遇。DMA 混进来以后，同一把刀多砍了一个对象。

    主线：腈长成四唑

    Ar 代表药物分子的联苯骨架。四唑环与案例图 2 相同。

    全部反应式

    设计之内：做药，再把叠氮销毁

    1. 一四唑成环（[3+2] 环加成）
      Ar–C≡N + NaN₃ → Ar–CN₄⁻ Na⁺ →(H⁺) Ar–CN₄H
      DMF 中加热，常加路易斯酸或铵盐活化腈基。叠氮化钠过量，反应完釜里还剩 N₃⁻。四唑 N–H 的 pKa 约 4.5–4.9。
    2. 二残余叠氮遇酸
      N₃⁻ + H⁺ ⇌ HN₃　（pKa 4.7）
      叠氮酸沸点 37 °C，易挥发、剧毒、易爆。这是非淬灭不可的原因。
    3. 三亚硝酸钠遇酸
      NO₂⁻ + H⁺ ⇌ HNO₂　（pKa ≈ 3.3）
      pH 2.8 时，大约四分之三的亚硝酸根已经变成 HNO₂。
    4. 四亚硝化物种
      2 HNO₂ ⇌ N₂O₃ + H₂O
      HNO₂ + H⁺ ⇌ H₂O–NO⁺ ⇌ NO⁺ + H₂O
      pH 2–4 以 N₂O₃ 为主，酸更强时 NO⁺ 的份额上升。若用盐酸酸化，还会有 HNO₂ + H⁺ + Cl⁻ ⇌ ClNO + H₂O，氯离子起催化作用。
    5. 五淬灭的本职
      HN₃ + HNO₂ → N₂↑ + N₂O↑ + H₂O
      经亚硝酰叠氮 N₃–N=O 分解。实验室手册也写作 2 NaN₃ + 2 HNO₂ → 3 N₂ + 2 NO + 2 NaOH。两种写法都要求亚硝酸过量，才能把叠氮清干净。

    设计之外：溶剂带来的支线

    1. 六DMF 水解
      HCON(CH₃)₂ + H₂O → HCOOH + (CH₃)₂NH
      酸、碱催化，加热加快。
    2. 七DMF 热分解
      HCON(CH₃)₂ → CO + (CH₃)₂NH
      接近沸点（153 °C）时缓慢发生，酸碱杂质会加速。蒸馏回收恰好提供这种条件。
    3. 八胺的酸碱平衡
      (CH₃)₂NH₂⁺ ⇌ (CH₃)₂NH + H⁺　（pKa 10.73）
      pH 2.8 时游离胺只占约 10⁻⁸，其余都是不反应的铵离子。反应仍然能走，只是被这个比例拖慢。
    4. 九亚硝化：NDMA 的生成
      (CH₃)₂NH + N₂O₃ → (CH₃)₂N–N=O + HNO₂
      速率 = k [(CH₃)₂NH] [HNO₂]²
      对亚硝酸是二级：N₂O₃ 要两分子 HNO₂ 才凑得出来。
    5. 十亚硝酸自身分解
      3 HNO₂ → HNO₃ + 2 NO + H₂O
      2 NO + O₂ → 2 NO₂　　NO + NO₂ ⇌ N₂O₃
      淬灭放出的氮氧化物在釜顶空间里仍是亚硝化试剂，通风和氮气吹扫有用。

    补救：把多余的亚硝酸清掉

    1. 十一氨基磺酸
      HNO₂ + H₂NSO₃H → N₂↑ + H₂SO₄ + H₂O
      快，产物只有氮气和硫酸，工艺上最常用。
    2. 十二抗坏血酸
      C₆H₈O₆ + 2 HNO₂ → C₆H₆O₆ + 2 NO + 2 H₂O
      把亚硝酸还原成 NO。有氧时 NO 会重新变回亚硝化物种，更适合用在分析稀释液里。
    3. 十三尿素
      CO(NH₂)₂ + 2 HNO₂ → CO₂ + 2 N₂ + 3 H₂O
      便宜，但比前两种慢。

    进了人体之后：限度为什么是纳克级

    1. 十四代谢活化
      (CH₃)₂N–NO →(CYP2E1) HOCH₂–N(CH₃)–NO
      → HCHO + CH₃–N=N–OH → CH₃–N₂⁺
      NDMA 本身不直接损伤 DNA。肝脏的 CYP2E1 在甲基上加一个羟基，分子随即散架，放出甲基重氮离子，把甲基接到 DNA 碱基上（如 O⁶-甲基鸟嘌呤）。这是它致突变、致癌的化学基础。

    速率之山

    How fast, and where

    仲胺的亚硝化有一条经典的速率式（Mirvish，1975）。把它画成一座山：横向是 pH，纵深是亚硝酸根浓度，高度是 NDMA 的生成速率。三个坐标同时在变，所以这里用立体的画法。

    速率 = k · [DMA]总 · [NO₂⁻]总² · g(pH)
    g(pH) = 4 Ka [H⁺](Ka + [H⁺])²

    k = 0.0017 M⁻²·s⁻¹（二甲胺，25 °C，水相，最适 pH 处）。g 在 pH = pKa(HNO₂) 时等于 1；这里按 Mirvish 实测的最适 pH 取 3.4。

    为什么是一道山脊

    pH 低，亚硝酸多，可是胺几乎全被质子化，没有孤对电子可用。pH 高，游离胺多了，亚硝酸却变回了不反应的亚硝酸根。两头都慢，中间最快。沿亚硝酸浓度方向，山一直往上爬：浓度每高 10 倍，速率高 100 倍。

    pH 2.8 和 2.9 是同一个地方

    按这条式子，pH 2.9 的速率是山脊处的 73%，pH 2.8 是 64%。两种工艺都站在山脊旁边。pH 解释不了新旧工艺的差别，但没有它，NDMA 根本生成不了。推断

    平方项决定了「在哪里生成」

    按水洗数据回推，淬灭结束时亚硝酸根约 4.5 mM；末次水洗后是 0.07 mM（3.2 mg/L）。两处的速率相差约 4000 倍，加料过程中的瞬时浓度还会更高。所以 NDMA 若是原位生成的，主要生成在淬灭釜里，不在水洗之后。推断

    量级够不够，是个开着的问题

    按默认这组数（DMA 11.8 mg/L，4.5 mM，1 小时，8 L/kg），只能生成约 0.012 ppm，比 0.52 ppm 少四十倍左右。瞬时亚硝酸浓度高出六七倍就能补上这个差距；釜内新生成的 DMA、更长的停留、氯离子催化也都可以。但它同样可能说明，有一部分 NDMA 是随溶剂带进来的。动力学给不出答案，它只告诉我们该去测什么。补充

    这是稀水溶液、25 °C 的动力学。真实体系是 DMF、水和有机相的混合物，温度不同，还有卤离子催化。这里只取量级和趋势，不是预测值。「每千克 API 对应 8 L 反应液」是为了换算随手取的假设，案例没有给。

    水洗与物料账

    Purge and mass balance

    水洗这一步没有新反应，只有稀释和分配。案例给的两个亚硝酸根数字，正好够算出一次水洗的力气。

    一洗约等于八分之一

    历史工艺实测现行工艺实测按 8 倍回推

    三洗后 0.4 mg/L，两洗后 3.2 mg/L，只差一洗，差 8 倍。如果两种工艺淬灭后的起点相同、每一洗的效率也相同，往回推，淬灭结束时约 200 mg/L（4.5 mM）。推断 这是两个点连出来的线，要靠逐洗取样来验证。

    补上第三洗，够不够

    NDMA 与水互溶（log P ≈ −0.57），水洗理应带得走，但带走多少取决于它在有机相和水相之间怎么分配，这个数只能实测：在水洗前加标已知量的 NDMA，看每一洗后还剩多少。补充

    DMA 的账：够不够生成 0.52 ppm

    这笔账说明什么

    进料里的 DMA 远远过量。要解释 0.52 ppm，只需要其中千分之几变成 NDMA 并留在产品里。推断

    更要紧的是第二行：历史工艺的 DMA 虽然低于 1.0 mg/L，按化学计量仍然够超出限度几十倍。旧工艺要是真的干净，可能是靠第三洗在兜底，也可能只是没测过。这就是为什么旧批次的留样一定要用同一个方法检测。补充

    柒

    看不见的 0.52

    Confirming identity and amount

    筛查只说「那里有东西」。要回答它是不是 NDMA、到底多少，方法得换。

    常规 UV 为什么看不见

    • 浓度上差 1250 倍：定量限 500 ppm，限度 0.40 ppm。
    • NDMA 分子小，紫外吸收集中在 230 nm 附近且不强，在色谱上保留也弱，容易埋在溶剂峰和基质里。
    • UV 只给保留时间和峰面积，不给「它是谁」。

    案例 两种工艺的 UV 结果相同，所以它也分不出新旧工艺。

    确证方法：LC-MS/MS，同位素稀释

    • 样品溶在加了亚硝酸清除剂的稀释液里，低温、避光，防止前处理时现生成。
    • 反相色谱把 NDMA 和残留 DMF、API 主峰分开；主峰切到废液，不进质谱。
    • 正离子模式（APCI 或 ESI），多反应监测。
    • 定量限做到限度的 10%–30%（0.04–0.12 ppm）以下，至少不高于 0.40 ppm。

    案例 摘要里已经写明：对照品、同位素内标、定量限 ≤ 0.40 ppm。

    凭什么说「它就是 NDMA」

    • 保留时间与 NDMA 对照品一致。
    • 两对离子（定量 + 定性）的比值与对照品一致。
    • 与同位素内标 NDMA-d₆ 共流出。
    • 加标回收合格，标准加入法结果一致。
    • 用第二种原理不同的方法复核：高分辨质谱的精确质量 75.0553。

    防假象的几件小事

    • 同一份样品，稀释液加与不加清除剂各做一次。加了以后读数下降，说明前处理时在现生成。
    • 含亚硝酸根和胺的样品不走高温进样口；若用气相法，必须有液相法交叉验证。
    • 报告 DMF 与 NDMA 的色谱分离度。
    • 试剂空白要做全：实验室自己的 DMF、滤膜、手套都可能带入 NDMA。

    一个专属于这个案子的陷阱：DMF 的同位素峰

    DMF 正是工艺溶剂，产品里难免残留。质子化的 DMF 是 m/z 74.0600，它含一个 ¹⁵N 的同位素峰落在 75.0571，离 NDMA 的 75.0553 只差 0.0018。分辨率不够、色谱又没分开的话，两个峰会并成一个。补充

    NDMA 75.0553DMF（¹⁵N）75.0571DMF（¹³C）75.0634仪器实际看到的合峰

    假设两者完全共流出、电离响应相同，这在真实样品里并不成立，所以这张图只说明量级：残留 DMF 的限度是 880 ppm（ICH Q3C），而一百多 ppm 的 DMF 就足以在低分辨下凑出 0.5 ppm 级别的假信号。真实方法靠色谱分离、离子对的选择性和足够的分辨率三重保险。筛查用的是什么方法，案例没有说。

    捌

    断案：证据、推断、待检验

    What we know, what we think, what to test

    摘要里有一句话很要紧：筛查既没有认出这个峰，也没有定出它的浓度。先把手里的材料按分量分开摆。

    案例 数据直接支持的

    • 筛查在约 0.52 ppm 处有信号，身份未定。
    • 回收 DMF（R-21）的 DMA 为 11.8 mg/L，原生 DMF 低于 1.0。
    • 水洗从三次减到两次；末次水洗后亚硝酸根 0.4 → 3.2 mg/L。
    • 淬灭 pH 2.9 与 2.8，两种工艺几乎相同。
    • UHPLC-UV 在两种工艺下结果相同，定量限 500 ppm。
    • 回收商共用设备，批次追溯不完整。
    • 历史工艺没有做过痕量筛查。

    推断 化学上说得通的

    • 信号最可能是 NDMA：前体、试剂、酸度三样齐全。
    • 若是原位生成，主要发生在淬灭釜里。
    • 少一次水洗，清除就少一轮。
    • 回收蒸馏保留了 DMA，或者在不断产生新的 DMA。
    • 如果确是 0.52 ppm 的 NDMA，就超过了 0.40 ppm 的限度。

    待检验 现在答不了的

    • 这个峰到底是什么，准确浓度多少。
    • 是在釜里生成的，还是随溶剂带进来的。
    • 旧工艺的批次里有没有 NDMA。
    • 每一洗对 NDMA 的清除倍数。
    • 成环时釜内的 DMF 是否也在降解出 DMA。
    • 有没有别的亚硝胺，比如 NDEA。
    • 干燥和贮存期间它会不会继续长。

    五种说法，各自预言不同的图案

    每一种解释都对「沿工艺逐点取样会看到什么」和「2×2 对照实验会得到什么」给出不同的预言。选一种说法，看它预言的样子。

    玖

    对策：不让三样东西同时在场

    Control strategy

    亚硝胺要三样东西凑在一起：可亚硝化的胺、亚硝化试剂、足够的时间。对策不指望哪一道关单独挡住，而是每一关各削掉一样。

    关一 · 溶剂

    回收 DMF 先过检验再进釜

    做法
    回收 DMF 的质量标准加上 DMA、NDMA、NDEA 和亚硝酸根。每批检验，合格才放行。回收商用专用设备，或者清洁后经过验证；每批附带走过哪些罐的谱系。只回收这一步的 DMF，也只回用到这一步。调查期间四唑步骤暂用原生 DMF，R-21 隔离。
    标准
    DMA ≤ 1.0 mg/L，这是历史工艺的已知水平，等加标实验出来再调。NDMA 不得检出。
    道理
    速率对 DMA 是一级，降到十二分之一，生成也降到十二分之一。同时堵住「带入」这条路。
    代价
    每批多一组检测。专用设备会抬高回收费用，但 80% 的溶剂回收大体还划算。
    关二 · 淬灭

    让胺见不到亚硝酸，或者见得越短越好

    做法
    首选改顺序：先分相，让含产品的有机相离开，再在含叠氮的水相里淬灭。必须同釜淬灭时，按残余叠氮的实测量投亚硝酸钠，用淀粉–碘化钾试纸判终点；低温，限定停留时间；淬灭完立即加氨基磺酸清掉余量。
    标准
    亚硝酸钠过量有上限。温度、时间写进批记录并设限。清除后亚硝酸根检测为阴性，才进入水洗。
    道理
    速率对亚硝酸是二级，过量减半，速率降到四分之一。清除剂让胺和亚硝酸同时在场的时间归零。
    代价
    改顺序要重新验证并申报变更。同釜方案只多一种便宜的辅料和一次中控。
    关三 · 水洗

    把第三洗请回来，并用数据说话

    做法
    经变更控制恢复第三次水洗。用加标实验测出每一洗对 NDMA 和亚硝酸根的清除倍数，再按数据定水洗次数和用水量。
    标准
    末次水洗液亚硝酸根 ≤ 0.5 mg/L，历史工艺是 0.4 mg/L。
    道理
    已经生成的 NDMA，只有这一步能带走。
    代价
    每批多一次水洗的工时和废水。
    关四 · 放行

    NDMA 写进质量标准，每批都测

    做法
    用经验证的 LC-MS/MS 每批检验 NDMA。UHPLC-UV 继续管常规有关物质，两种方法各管各的。
    标准
    NDMA ≤ 0.40 ppm。内控警戒线取限度的 30%，即 0.12 ppm。方法定量限不高于限度的 10%，即 0.04 ppm。
    道理
    前三关降低概率，这一关保证漏网的批次出不了厂。
    代价
    仪器和方法验证是最大的一笔投入。可以先委托有资质的实验室，批量上来再自建。
    关五 · 体系

    别让下一次「小改动」再溜过去

    做法
    「水洗三次改两次」这类改动必须走变更控制和亚硝胺风险评估（ICH Q9、M7）。回收商定期审计，质量协议写明设备、清洁和追溯要求。已放行的批次做风险评估，并按法规与监管机构沟通。
    道理
    这次的两个变化，换溶剂来源和减水洗，单看都像是合理的降本，合在一起才出事。

    叠几道关，能降到哪里

    怎么证明它一直有效

    1. 工艺验证批。连续至少三批逐点取样，确认成品 NDMA 稳定低于限度的 10%–30%。
    2. 三张控制图。进料 DMF 的 DMA、末次水洗液的亚硝酸根、成品的 NDMA，各设警戒限和行动限，持续画下去。
    3. 变更即重评。溶剂来源、回收商、水洗次数、淬灭参数、批量，任何一项变动都触发重新评估。
    4. 供应商。回收商定期审计；每批回收溶剂附谱系和检验报告。
    5. 稳定性。留样长期考察，NDMA 不随时间增长。
