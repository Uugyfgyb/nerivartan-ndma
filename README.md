# 一滴墨的来历 · Nerivartan 亚硝胺案

CSU Fall 2026 Case Competition《A Pernicious Manufacturing Problem》的水墨风格讲解页。沿着摘要《Find Potential Nitrosamine Contamination in Nerivartan Manufacturing》的思路，把全工艺流程、全部化学反应、确证方法和控制策略画出来。

**在线看**：<https://uugyfgyb.github.io/nerivartan-ndma/>

**离线看**：下载 [index.html](index.html) 双击即可。样式、脚本、三维坐标都已内嵌，不需要服务器。字体从 Google Fonts 加载，断网时退回系统字体。页面跟随系统深浅色，按电脑宽屏排版，窄屏自动退成单栏。

二维用在流程、结构式和数据图上，这些东西平着看最清楚。三维只用在三处：分子的立体形状、反应机理中原子怎么走、以及 pH × 亚硝酸根 × 速率这个三变量关系。

## 哪些是数据，哪些不是

页面里每个论断都带标记：

- **案例**：案例文件直接给出的数据。
- **推断**：由化学原理推出、没有数据直接证明。
- **待检验**：需要新实验才能回答。
- **补充**：摘要之外补进去的想法，用之前要自己核对。

几处要特别留意：

- 速率常数 k = 0.0017 M⁻²·s⁻¹ 和最适 pH 3.4 凭记忆取自 Mirvish (1975) 的稀水溶液数据，真实体系是 DMF–水混合物，只能看量级。
- 「每洗稀释 8 倍」「淬灭结束时约 4.5 mM」是从案例的两个亚硝酸根数字回推的。
- 每千克 API 用 8 L DMF、NDMA 每洗清除 4 倍，是演示用的假设值。
- 三维反应动画的坐标由标准键长键角搭出，帧间插值，是示意，不是量化计算的反应路径。
- 「拾」里的参考文献前七条是凭记忆列的，引用前请逐条查原文。

## 结构

```text
nerivartan-ndma/
├── index.html        # 成品：单文件，由 tools/build.py 生成，不要直接改
├── src/
│   ├── index.html    # 正文
│   ├── ink.css       # 水墨样式（纸色、朱砂、花青、赭石）
│   ├── ink3d.js      # 三维引擎：墨点分子、反应插值、层叠山形曲面；纯 canvas，无依赖
│   ├── page.js       # 各章的数据和交互
│   └── geom.js       # 三维坐标，由 tools/geom.py 生成
└── tools/
    ├── geom.py       # 由键长键角生成分子和反应关键帧（需要 numpy）
    └── build.py      # 把 src/ 内嵌成根目录的 index.html
```

改了 `src/` 之后运行 `python3 tools/build.py`。改了三维坐标先运行 `python3 tools/geom.py`。
